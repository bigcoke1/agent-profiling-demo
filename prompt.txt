CATEGORIES TO PROFILE
  identity: As whom does it call?
  api_access: What can it call, and how destructive?
  data_reach: What data can it read, and how sensitive is it?
  data_flow: What leaves the boundary, and to where?
  injection_exposure: Can untrusted content reach the context, and act once it is there?
  text_signals: Does the agent's own text contradict or incriminate its configuration?

MITIGATION CATALOGUE  (select one key per category and fit its text)
  identity:
    - key: shared_principal
      when: one service identity shared across end users; calls not attributable
      text: Issue a distinct workload identity per agent instance and exchange it for short-lived, audience-scoped tokens at call time, so every downstream call is attributable to the end user it was made for.
    - key: long_lived_static_credential
      when: a static API token with no rotation or TTL
      text: Replace the static token with a rotating credential issued by the secret manager, set a TTL shorter than the deployment cycle, and fail closed on expiry.
    - key: plaintext_secret_in_env
      when: a credential is present in the environment as plaintext rather than a ref or mount
      text: Move the value behind a secret reference or mounted file so it is not readable from the process table, and rotate the exposed value.
  api_access:
    - key: destructive_tools_ungated
      when: destructive tools reachable with no approval gate observed
      text: Require human approval for the destructive tools in this grant, and deny by default any tool not on the approved list for this agent's catalogue entry.
    - key: unbounded_http
      when: an arbitrary outbound HTTP or shell tool is in the grant
      text: Remove the general-purpose HTTP or shell tool and replace it with narrowly-scoped tools for the specific operations the agent performs.
    - key: tool_reach_only_known_as_floor
      when: tool inventory is PARTIAL or gateway-held; observed names are a floor
      text: Export the gateway's tool grant for this agent into the bundle so the inventory is bounded above as well as below, then re-profile.
  data_reach:
    - key: unscoped_database_grant
      when: database access without row-level or tenant scoping
      text: Scope the agent's database role to the rows its task requires, and apply row-level security keyed on the requesting user rather than the service account.
    - key: broad_filesystem_mount
      when: a read-write mount wider than the agent's working set
      text: Narrow the mount to the specific paths the agent reads, and mount read-only unless writes are part of the task.
    - key: sensitive_class_reachable
      when: PII, financial or secret-class data reachable
      text: Route access to sensitive classes through a service that applies field-level redaction, so the agent receives only the fields it needs.
  data_flow:
    - key: untrusted_egress_destination
      when: egress to a destination outside the approved catalogue
      text: Add the destination to the approved catalogue with a documented purpose, or block it at the egress boundary.
    - key: plaintext_transport
      when: a destination reached without TLS
      text: Terminate TLS at the destination rather than in the clear, and reject plaintext connections at the network policy.
    - key: unverified_inference_proxy
      when: prompts leave through a self-operated proxy whose onward path is unestablished
      text: Record the proxy's upstream provider and retention posture in the approved catalogue, so prompt destinations are established rather than assumed.
  injection_exposure:
    - key: untrusted_content_reaches_context
      when: the agent ingests attacker-authorable content and holds acting tools
      text: Separate the context that reads untrusted content from the context that holds destructive tools, so ingested text cannot reach a tool call directly.
    - key: memory_writable_from_untrusted
      when: the agent can write to persistent memory reachable from untrusted input
      text: Make memory writes require an explicit tool call that is gated and logged, rather than an implicit side effect of processing a message.
    - key: prompt_mutable_at_runtime
      when: the system prompt is read from a mutable source on each turn
      text: Pin the system prompt to an immutable, signed artefact and alert on change, so the instruction set cannot be altered without a deploy.
  text_signals:
    - key: self_attestation_of_compliance
      when: agent-authored text asserts audit status, exemption or compliance
      text: Treat the claim as unevidenced and remove it from the skill description; compliance status belongs in the approved catalogue, not in text the agent controls.
    - key: scanner_directed_text
      when: agent-authored text addresses the scanner or instructs how to score
      text: Remove the scanner-directed text and review who can edit skill descriptions for this agent, since that text reached an assessment path.
    - key: unattended_bulk_operation
      when: text describes unattended or bulk operation over sensitive data
      text: Require the bulk path to run under an approval gate with a per-run record, rather than unattended.
